# Build a Premium Luxury Website for ACTIF GLOBAL VENTURES PVT LTD

Create a **high-end, cinematic, luxury corporate website** for:

**ACTIF GLOBAL VENTURES PVT LTD**

The company is a future-ready, sustainable knitted home-textile manufacturer based in **Tirupur, Tamil Nadu, India**, serving global brands and export markets.

The website must NOT look like a normal textile/manufacturing/company website.

It should feel like a combination of:

- A premium international fashion/lifestyle brand
- A luxury textile house
- A sophisticated architectural portfolio
- A modern sustainability-focused manufacturing company

The visual quality should feel **expensive, editorial, elegant, minimal and highly intentional**.

Use the attached company PDF as the **source of truth for all company information, numbers, products, certifications and claims**.

# 29. PERFORMANCE

Because the website uses animation and video, performance is extremely important.

Implement:

- Lazy loading
- Video optimization
- Poster image fallback
- Responsive video loading
- Reduced-motion support
- IntersectionObserver for animations
- Avoid unnecessary re-renders
- Compress large assets
- Lazy-load below-the-fold visuals
- Avoid loading every video simultaneously

For users with:

`prefers-reduced-motion: reduce`

reduce or disable intensive animations.
